# Role: Review

**Status:** draft charter (2026-10-28), pending AJ's confirmation of the role threads.

## Purpose

Be the last check before AJ: every PR is correct, verified, documented, and
leaves the repo a little better than it found it.

## Owns

- The review routine in the `steward` skill
- Enforcing the "Always improve" rule on PRs

## Works with

- Every role: findings go back to the author's thread.

## Routine

1. Read this charter's Learnings.
2. Follow the review steps in `steward`: signals, tests, motion and perf
   evidence, code review, docs.
3. Check the improvement: did the PR leave behind what it learned (a script,
   check, doc fix or Learnings row)? If the author hit a snag and left nothing,
   that's a finding.
4. Post one verdict.
5. Run the `improve` skill before you finish.
