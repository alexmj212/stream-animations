**Calculate shared timing (single source of truth):**
```javascript
const text = urlParams.get('text') || 'Default celebration text';
const baseColor = getColorFromURL(); // Existing function

// Calculate hold duration from text length (ShadeBar pattern)
const holdDurationMs = ShadeBar.calculateHoldDuration(text);

// Calculate total duration (enter + hold + exit)
const totalDurationMs = config.shade.durations.entryMs + holdDurationMs + config.shade.durations.exitMs;
```

**Create curtains with shared duration:**
```javascript
const baseHSL = hexToHSL(baseColor);
const topCurtain = new CurtainBar(ctx, canvas, 'top', baseHSL, totalDurationMs);
const bottomCurtain = new CurtainBar(ctx, canvas, 'bottom', baseHSL, totalDurationMs);
```

**Update existing ShadeBar instantiation:**
ShadeBar constructor already accepts holdDurationMs, no changes needed.

**Update animation loop - CRITICAL rendering order:**
```javascript
function animate(timestamp) {
  const deltaTime = deltaTimer.update(timestamp);

  ctx.clearRect(0, 0, canvas.width, canvas.height);

  // Update all components with same deltaTime
  topCurtain.update(deltaTime);
  bottomCurtain.update(deltaTime);
  shadeBar.update(deltaTime);

  // RENDERING ORDER CRITICAL (RESEARCH.md Pitfall 1)
  // Draw curtains FIRST (background layer)
  topCurtain.draw();
  bottomCurtain.draw();

  // Draw text LAST (foreground layer - always visible on top)
  shadeBar.draw();

  // Continue until all components inactive
  const anyActive = topCurtain.active || bottomCurtain.active || shadeBar.active;
  if (anyActive) {
    requestAnimationFrame(animate);
  } else {
    lifecycle.cleanup(); // AnimationLifecycle cleanup
  }
}
```

**Add curtain-specific config (if not already in config.js):**
Check config.shade for curtain section. If missing, add to config.js:
```javascript
curtains: {
  opacity: 0.5,        // Semi-transparent overlay
  barCount: 6          // Horizontal bars per curtain
}
```

**Why rendering order matters:**
CONTEXT.md specifies "Text always renders ABOVE curtains (not clipped by them)". Canvas rendering order determines z-index - last drawn appears on top. Drawing text after curtains ensures text is always fully visible.

**Why shared totalDurationMs:**
RESEARCH.md Pitfall 3 warns: "Different duration calculations cause desynchronization." Calculate totalDurationMs once and pass to all components to ensure they finish simultaneously.
