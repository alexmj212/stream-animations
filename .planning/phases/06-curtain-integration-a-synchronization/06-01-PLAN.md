<task type="auto">
  <name>Create CurtainBar class with three-phase animation</name>
  <files>src/shade/CurtainBar.js</files>
  <action>
Create CurtainBar.js extending AnimatedBar following the stinger three-phase pattern (adapted for vertical movement).

**Class structure:**
- Extends AnimatedBar base class
- Constructor accepts: ctx, canvas, position ('top' or 'bottom'), baseHSL, totalDurationMs
- Properties:
  - opacity: 0.5 (middle of CONTEXT 0.4-0.6 range)
  - targetHeight: canvas.height / 2 (covers 50% of viewport)
  - phase: 'enter' | 'hold' | 'exit'
  - Position tracking: y (current), startY (offscreen), targetY (final hold position)
- Phase durations from config.shade.durations (entryMs, exitMs) + calculated holdDuration

**Three-phase animation logic (in update method):**
- Enter phase: Curtain moves from offscreen to target position using easeInOutCubic
  - Top curtain: startY = -targetHeight (above viewport), targetY = 0 (top edge)
  - Bottom curtain: startY = canvas.height (below viewport), targetY = canvas.height / 2 (centerline)
- Hold phase: Static position at targetY (no movement)
- Exit phase: Curtain returns to offscreen using easeInOutCubic

**Draw method:**
- Semi-transparent overlay using ctx.globalAlpha = this.opacity
- Gradient fill using baseHSL (matches stinger/sidebar pattern from RESEARCH.md)
- createLinearGradient from curtain top to bottom
- Gradient stops: baseHSL.l at top, baseHSL.l - 20 at bottom (darker gradient)
- Apply brightness multiplier: config.shade.brightness (0.8)
- IMPORTANT: Wrap in ctx.save()/restore() to prevent globalAlpha persistence (RESEARCH.md Pitfall 5)

**Why NOT use AnimatedBar's bar rendering:**
AnimatedBar is designed for skewed/rotated bars. Curtains are simple rectangles with gradients. Create custom draw method using ctx.fillRect with gradient fill. Inherit from AnimatedBar for easeInOutCubic and shared patterns, but override draw().

<task type="auto">
  <name>Embed horizontal bars with clipping</name>
  <files>src/shade/CurtainBar.js</files>
  <action>
Add continuously animating horizontal bars inside CurtainBar.

**Create initBars() method (called from constructor):**
- Generate 6 horizontal bars (balance between visual density and performance)
- Use AnimatedBar instances with type='horizontal'
- Randomize direction: Math.random() > 0.5 ? 1 : -1 (both L-R and R-L)
- Position bars evenly within curtain area:
  - Top curtain: y from 0 to canvas.height/2
  - Bottom curtain: y from canvas.height/2 to canvas.height
- Visual properties (match stinger pattern from RESEARCH.md):
  - 70% white bars: isWhite = Math.random() > 0.7
  - White bars: saturation=0, lightness=100*brightness, width 20-50px
  - Colored bars: hue variation ±20 from baseHSL, width 40-100px
  - Opacity: 0.6-1.0 (from config.stinger.opacity)
  - Skew: -15 degrees (config.stinger.horizontal.skewAngle)
- Speed: traverse canvas in 2-3 seconds (canvas.width + 400) / (2 + Math.random())
- Start offscreen: x = direction === 1 ? -200 : canvas.width + 200

**Update bars in update() method:**
- Update bar positions: bar.x += bar.speed * bar.direction * deltaTime
- Wrap around when offscreen:
  - If direction === 1 and x > canvas.width + 200: reset to x = -200
  - If direction === -1 and x < -200: reset to x = canvas.width + 200

**Clip bars in draw() method:**
- Draw curtain fill first (background layer)
- Create clipping region matching curtain's current visible area:
  - ctx.save()
  - ctx.beginPath()
  - Top curtain: ctx.rect(0, 0, canvas.width, Math.max(0, this.y + this.targetHeight))
  - Bottom curtain: ctx.rect(0, this.y, canvas.width, this.targetHeight)
  - ctx.clip()
- Draw bars using each bar's drawBar() method from AnimatedBar
- ctx.restore() to remove clipping

**Why clip bars to curtain boundaries:**
RESEARCH.md Pitfall 4 explains bars must not render outside curtain area during enter/exit phases. Without clipping, bars would be visible above/below curtain during transitions.

**Why continuous bar animation:**
CONTEXT.md specifies "Bars animate throughout entire animation (enter/hold/exit phases)" and "Bars visible and moving from moment curtains start entering until they finish exiting."
