Implement PERF-01 requirement: Offscreen canvas pre-rendering for 10x+ text rendering speedup.

**Add properties to constructor (line 70-85 area):**
```javascript
// Offscreen canvas for text caching (created in init() after font loads)
this.textCanvas = null;
this.textCanvasWidth = 0;
this.textCanvasHeight = 0;
```

**In init() method (after line 111 visual center offset calculation):**

1. Calculate offscreen canvas dimensions with shadow padding:
   - Width: `Math.ceil(this.textWidth + 40)` (20px padding each side for 8px blur + 4px offset + safety)
   - Height: `Math.ceil(actualAscent + actualDescent + 40)` (20px padding top/bottom)
   - Store in `this.textCanvasWidth` and `this.textCanvasHeight`

2. Create offscreen canvas:
   ```javascript
   this.textCanvas = document.createElement('canvas');
   this.textCanvas.width = this.textCanvasWidth;
   this.textCanvas.height = this.textCanvasHeight;
   const offCtx = this.textCanvas.getContext('2d', { alpha: true });
   ```
   CRITICAL: Use `{ alpha: true }` to ensure transparent background (not black).

3. Pre-render text with shadow to offscreen canvas:
   - Copy all text properties from config.shade.text
   - Set font, fillStyle, textBaseline='alphabetic'
   - Set shadow properties (color, blur, offsetX, offsetY)
   - Calculate baseline Y position: `20 + actualAscent` (padding + ascent)
   - Call `offCtx.fillText(this.text, 20, baselineY)` ONCE
   - Comment: "PERF-01: Pre-render text once to offscreen canvas (10-20x faster than fillText per frame)"

**In draw() method (replace lines 251-268):**

Replace entire draw() implementation with cached canvas rendering:
```javascript
draw() {
  this.ctx.save();

  // PERF-01: Draw pre-rendered text from offscreen canvas
  // This is 10-20x faster than calling fillText() with shadow every frame
  const drawX = this.x - 20; // Account for offscreen canvas padding
  const drawY = this.y - this.visualCenterOffset - 20; // Account for padding and centering

  this.ctx.drawImage(this.textCanvas, drawX, drawY);

  this.ctx.restore();
}
```

**Why these changes:**
- fillText() with large font (96px Jost bold) + shadow rendering is expensive (~10-15ms per frame)
- Pre-rendering to offscreen canvas once, then using drawImage() each frame reduces cost to ~0.5-1ms
- Research shows 10-20x speedup for complex text with shadows (exceeds PERF-01 requirement of 5x+)
- { alpha: true } ensures transparent background so text composites correctly over curtains
- Shadow padding prevents clipping at edges (blur extends beyond text bounding box)

  <name>Task 2: Migrate CurtainBar from globalAlpha to hsla() colors</name>
  <files>src/shade/CurtainBar.js</files>
  <action>
Implement PERF-03 requirement: Replace globalAlpha with hsla() colors for better GPU compositing efficiency.

**Current state audit:**
CurtainBar.js uses `this.ctx.globalAlpha = this.opacity` (line 349) to control curtain transparency. This requires save/restore overhead and prevents GPU premultiplied alpha optimization.

**In drawCurtain() method (lines 340-360 area):**

1. **Remove globalAlpha lines:**
   - Delete line 349: `this.ctx.globalAlpha = this.opacity;`
   - Delete line 312 if present: `this.ctx.globalAlpha = 1.0;`

2. **Update gradient.addColorStop() calls to include opacity:**

Current (using globalAlpha):
```javascript
gradient.addColorStop(0, `hsl(${h}, ${s}%, ${baseLightness}%)`);
gradient.addColorStop(1, `hsl(${h}, ${s}%, ${endLightness}%)`);
```

Replace with (opacity baked into color):
```javascript
gradient.addColorStop(0, `hsla(${h}, ${s}%, ${baseLightness}%, ${this.opacity})`);
gradient.addColorStop(1, `hsla(${h}, ${s}%, ${endLightness}%, ${this.opacity})`);
```

3. **Update comment on line 340:**
Change from: "Uses ctx.save/restore to prevent globalAlpha persistence"
To: "Uses hsla() colors with opacity baked in for GPU efficiency (PERF-03)"

4. **Verify save/restore still needed:**
CurtainBar uses clipping (ctx.clip()) which requires save/restore. Keep save/restore pairs but remove the globalAlpha usage within them.

**Why these changes:**
- hsla() with alpha channel allows GPU to optimize premultiplied alpha compositing
- Eliminates globalAlpha state management (no risk of affecting subsequent draws)
- Research shows rgba()/hsla() is preferred over globalAlpha for per-element transparency
- save/restore still needed for clipping region, but not for opacity

**What NOT to change:**
- Do NOT remove save/restore around drawCurtain() - still needed for ctx.clip()
- Do NOT change bar rendering within curtains - bars may already use correct approach
- Do NOT change curtain entry/exit animation logic - only color specification
