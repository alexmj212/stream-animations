**BackgroundBar.js timing migration (frame-based → millisecond-based):**

Current implementation uses frame-based durations (RESEARCH.md lines 96-98):
```javascript
// Current: Frame-based with framesToSeconds() helper
this.fadeInDuration = AnimatedBar.framesToSeconds(config.background.timing.fadeInFrames);
this.fadeOutDuration = AnimatedBar.framesToSeconds(config.background.timing.fadeOutFrames);
// fadeInFrames: 120 = 2 seconds, fadeOutFrames: 120 = 2 seconds
```

Replace with millisecond-based using config.background.durations (with shared fallback):
```javascript
// New: Millisecond-based with direct conversion
const entryMs = config.background.durations?.entryMs ?? config.shared.durations.entryMs;
const exitMs = config.background.durations?.exitMs ?? config.shared.durations.exitMs;
const holdMinMs = config.background.durations?.holdMinMs ?? 30000; // 30 seconds min
const holdMaxMs = config.background.durations?.holdMaxMs ?? 120000; // 120 seconds max

this.fadeInDuration = entryMs / 1000;  // Convert to seconds for deltaTime
this.fadeOutDuration = exitMs / 1000;
this.visibleDuration = (holdMinMs + Math.random() * (holdMaxMs - holdMinMs)) / 1000;

// Direction transition timing (currently: 180 frames = 3 seconds)
const transitionMs = config.background.durations?.transitionMs ?? 3000;
this.directionTransitionDuration = transitionMs / 1000;
```

**IMPORTANT conversions to preserve feel:**
- fadeInFrames: 120 @ 60fps = 2000ms → use config.background.durations.entryMs (2000ms from Plan 01)
- fadeOutFrames: 120 @ 60fps = 2000ms → use exitMs (2000ms)
- visibleFramesMin: 1800 @ 60fps = 30000ms, visibleFramesMax: 7200 = 120000ms
- directionTransitionFrames: 180 @ 60fps = 3000ms

// Colored bars

this.lightness = Math.max(10, baseLightness * brightness);  // Use config brightness
