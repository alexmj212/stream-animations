  <files>src/shared/perfStorage.js</files>
  <action>
Create src/shared/perfStorage.js following RESEARCH.md "localStorage Session Management" pattern:

1. Export PerformanceStorage class with:
   - constructor(maxSessions = 50): Store maxSessions, prefix = 'perf_session_'
   - saveSession(metrics): Create session object with:
     - id: crypto.randomUUID()
     - timestamp: new Date().toISOString() (ISO 8601 format)
     - scene: metrics.scene (string: 'background', 'stinger', 'sidebar')
     - duration: metrics.duration (milliseconds)
     - avgFPS: metrics.avgFPS
     - peakMemoryMB: metrics.peakMemoryMB
     - droppedFrames: metrics.droppedFrames
   - Wrap localStorage.setItem in try/catch for QuotaExceededError
   - On quota error: console.warn, call evictOldSessions(true) for aggressive cleanup
   - Call evictOldSessions() after successful save
   - evictOldSessions(aggressive = false):
     - Get all keys starting with prefix, sort chronologically (ISO 8601 sorts naturally)
     - Calculate limit: aggressive ? maxSessions * 0.5 : maxSessions
     - Remove oldest keys if count exceeds limit (FIFO eviction)
   - getSessions(): Return sorted array of parsed session objects, newest first
   - clearAll(): Remove all keys with prefix

Use exact code structure from RESEARCH.md to avoid pitfall #3 (localStorage bloat).
Add JSDoc comments for all methods.
</action>
