  <name>Execute 4-6 Hour Long-Duration Stability Test</name>
  <what>
    Run background.html?perf=true for 4-6 hours with periodic monitoring to validate memory stability, frame time consistency, and crash-free operation over streaming-length sessions. This is the final empirical validation of Phase 1-2 memory management and timing infrastructure.
  </what>
  <instructions>
    **Pre-Test Setup:**
    1. Clear browser data: Chrome Settings -> Privacy -> Clear browsing data (localStorage, cache)
    2. Close unnecessary applications (but not critical to simulate isolated environment - can use machine normally during test)
    3. Note hardware specs: chrome://gpu, CPU model
    4. Verify current config state:
       - Alpha channel: config.performance.alpha.background (true or false based on 03-07 audit)
       - Dirty rectangles: config.performance.dirtyRectangles.enabled (based on 03-09 decision)
       - Document current configuration for reference

    **Test Execution:**
    1. Open background.html?perf=true in dedicated Chrome window
    2. Position window so performance overlay is visible (top-right corner)
    3. Record start time: `new Date().toISOString()` in console, copy to text file (stability-test-log.txt)
    4. Press 'P' key if overlay not visible (should auto-show with ?perf=true)
    5. Observe initial metrics:
       - FPS: Should be ~60fps
       - Memory: Note starting value (e.g., 120MB)
       - P99: Should be <18ms
       - Dropped frames: 0 or very low
    6. Record initial metrics in stability-test-log.txt

    **During Test (4-6 hours):**
    You CAN use machine for other tasks during test - just keep browser window visible/active (not minimized).

    Every 30-60 minutes, check performance overlay and record in stability-test-log.txt:
    - Time elapsed: (e.g., T=30min, T=1h, T=1.5h, etc.)
    - FPS: Current value
    - Memory: Current value (MB)
    - P99: Current value (ms)
    - Dropped frames: Current count
    - Visual check: Animation still smooth? Any stuttering?

    **Monitoring Goals:**
    - Memory growth: Look for steady increase over time (leak indicator)
    - FPS stability: Should remain ~60fps throughout (no degradation)
    - P99 stability: Should remain <18-20ms (no frame time inflation)
    - Dropped frames: Should grow slowly or not at all
    - Visual quality: Should remain smooth (no visible stuttering or artifacts)

    **If Issues Occur During Test:**
    - Browser crash: Note time, restart, document in stability-test-log.txt
    - Animation freezes: Note time, check console for errors, document
    - FPS drops below 55fps sustained: Note time, check what changed (background tasks?)
    - Memory exceeds 300MB: Note time, potential leak - continue test to confirm trend

    **After 4-6 Hours:**
    1. Record end time: `new Date().toISOString()` in console
    2. Export session data: `window.perfMonitor.getSessions()` in console
    3. Copy full output to stability-session-data.json file
    4. Take final metric reading from overlay
    5. Calculate totals:
       - Total duration: End time - start time (in hours)
       - Memory growth: Final memory - initial memory (in MB)
       - Total dropped frames: Final count
       - Average FPS: From session summary

    **Expected Results:**
    - Duration: 4-6 hours completed without crashes
    - Memory: Stable or slight growth (<50MB over full session)
    - FPS: Consistent ~60fps (±2fps variation acceptable)
    - P99: Stable <20ms throughout
    - Dropped frames: <1% of total frames (for 60fps * 6 hours = ~1.3M frames, <13K dropped acceptable)
    - Visual quality: Smooth animation throughout, no degradation
  </instructions>
  <expected>
    stability-test-log.txt containing:
    - Start/end times (ISO 8601)
    - Periodic readings (every 30-60min): FPS, Memory, P99, Dropped frames
    - Visual quality notes at each checkpoint
    - Any issues encountered (crashes, stutters, anomalies)
    - Final totals: duration, memory growth, total dropped frames

    stability-session-data.json containing:
    - Full output from window.perfMonitor.getSessions()
    - Session summary with avgFPS, peakMemoryMB, droppedFrames, duration

    Successful completion criteria:
    - 4-6 hours without crashes
    - Memory growth <50MB (or <20% increase)
    - FPS stable ~60fps (no sustained drops below 55fps)
    - No visual degradation over time
  </expected>
