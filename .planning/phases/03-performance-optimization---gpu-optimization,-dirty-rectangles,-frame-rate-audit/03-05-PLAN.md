- Store visualize flag (whether to draw debug outlines)

Methods:

**setCanvas(canvas, ctx):**
- Store canvas and ctx for visualization

**addRegion(x, y, width, height):**
- Expand by safetyMargin: { x: x - margin, y: y - margin, width: width + margin*2, height: height + margin*2 }
- Push to regions array

**getMergedRegions():**
- Implement simple union merge (from RESEARCH.md):
  - Return empty array if regions.length === 0
  - Return regions as-is if regions.length === 1
  - Sort regions by x coordinate ascending
  - Iterate through sorted regions:
    - For each pair, check overlap using geometric test: !(r1.right < r2.left || r1.left > r2.right || r1.bottom < r2.top || r1.top > r2.bottom)
    - If overlap: merge into bounding box (min x/y, max right/bottom)
    - If no overlap: push current to merged array, continue
  - Return merged array
- Accept redrawing some clean pixels for simplicity (tradeoff: fast merge vs perfect minimal coverage)

**clearAndReset(ctx):**
- Get merged regions via getMergedRegions()
- For each merged region:
  - ctx.clearRect(rect.x, rect.y, rect.width, rect.height)
  - If visualize flag enabled: draw debug outline (strokeStyle red, lineWidth 2, strokeRect)
- Clear regions array (reset for next frame)

**reset():**
- Clear regions array

**getStats():**
- Return { regionCount: regions.length, mergedCount: getMergedRegions().length }

Use RESEARCH.md exact code structure to avoid pitfall #2 (overly aggressive merging adds CPU overhead).
Add JSDoc comments for all methods.
Export class as default and named export.

```javascript
/**
 * Calculate bounding box accounting for rotation/skew and shadow offset
 * @returns {{x: number, y: number, width: number, height: number}}
 */
getBoundingBox() {
    const shadowOffset = config.canvas.shadow.offsetX; // Read from config

    if (this.type === 'slanted') {
        // Rotated rectangle bounding box calculation
        const angle = this.angle * Math.PI / 180;
        const cos = Math.abs(Math.cos(angle));
        const sin = Math.abs(Math.sin(angle));
        const height = this.canvas.height * 1.5; // Full height for slanted bars

        // Calculate rotated bounding box
        const bboxWidth = this.width * cos + height * sin;
        const bboxHeight = this.width * sin + height * cos;

        return {
            x: this.x - bboxWidth / 2 - shadowOffset,
            y: this.y - shadowOffset,
            width: bboxWidth + shadowOffset * 2,
            height: bboxHeight + shadowOffset * 2
        };
    } else {
        // Skewed rectangle bounding box calculation
        const skewAngle = this.skew * Math.PI / 180;
        const skewOffset = Math.abs(this.height * Math.tan(skewAngle));

        // Calculate skewed bounding box
        return {
            x: this.x - skewOffset - shadowOffset,
            y: this.y - this.height / 2 - shadowOffset,
            width: this.width + skewOffset + shadowOffset * 2,
            height: this.height + shadowOffset * 2
        };
    }
}
```

**StingerBar-specific considerations:**

**SidebarBar-specific considerations:**

- Read shadowOffset from config
