<task type="auto">
  <name>Configure canvas mock in vitest setup</name>
  <files>vitest.config.js, vitest.setup.js</files>
  <action>
Create vitest.setup.js to initialize canvas mock:

```javascript
import 'vitest-canvas-mock';

// Re-initialize canvas mock after vi.resetAllMocks() if needed
import { setupVitestCanvasMock } from 'vitest-canvas-mock';
global.setupVitestCanvasMock = setupVitestCanvasMock;
```

Update vitest.config.js to include setupFiles:

```javascript
import { defineConfig } from 'vitest/config';

export default defineConfig({
  test: {
    globals: true,
    environment: 'jsdom',
    setupFiles: ['./vitest.setup.js'],
    coverage: {
      provider: 'v8',
      reporter: ['text', 'json', 'html'],
      exclude: [
        'node_modules/',
        'dist/',
        '**/*.config.js',
        '**/index.html'
      ]
    }
  }
});
```

This ensures canvas mock loads before any tests run, providing HTMLCanvasElement.prototype.getContext in jsdom.
  </action>
  <verify>grep "setupFiles.*vitest.setup" vitest.config.js confirms configuration, vitest.setup.js exists and imports vitest-canvas-mock</verify>
  <done>vitest.setup.js imports canvas mock, vitest.config.js references setupFiles</done>
</task>
