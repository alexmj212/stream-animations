# Requirements: Stream Animations v1.1

**Defined:** 2026-01-18
**Core Value:** The background animation must perform flawlessly with minimal CPU/GPU usage since it runs continuously throughout every stream.

## v1.1 Requirements

### Curtain Animation

- [x] **CURTAIN-01**: Semi-transparent curtains enter from top and bottom edges with configurable opacity
- [x] **CURTAIN-02**: Curtains use smooth easeInOutCubic easing for entry and exit animations
- [x] **CURTAIN-03**: Curtains follow three-phase lifecycle (enter → hold → exit) synchronized with text
- [x] **CURTAIN-04**: Curtain brightness matches existing scenes (0.8 multiplier for visual harmony)
- [x] **CURTAIN-05**: Curtain timing aligns with centralized config defaults and millisecond-based system

### Text Display

- [x] **TEXT-01**: Large readable text renders on canvas with explicit fillStyle for OBS compatibility
- [x] **TEXT-02**: Hold duration calculated dynamically from text length (250ms/word baseline)
- [x] **TEXT-03**: Text scrolls horizontally during hold phase with linear interpolation
- [x] **TEXT-04**: Text renders above curtains (always visible, not clipped to curtain boundaries)
- [x] **TEXT-05**: Minimum readability guarantee enforced (min/max duration bounds)
- [x] **TEXT-06**: Text remains fully visible throughout entire hold phase (no cutoff)
- [x] **TEXT-07**: Text "flies in" with curtains during enter, "flies out" during exit

### Configuration & Integration

- [x] **CONFIG-01**: Shade scene accepts URL parameters (?text, ?color, ?duration)
- [x] **CONFIG-02**: config.shade section added to centralized config.js with timing and style settings
- [x] **CONFIG-03**: Shade scene uses AnimationLifecycle for proper cleanup on OBS reload
- [x] **CONFIG-04**: Font loading integrated via document.fonts.ready to prevent race conditions
- [x] **CONFIG-05**: DeltaTimer provides frame-rate independent animation timing

### Performance & Testing

- [x] **PERF-01**: Offscreen canvas caching pre-renders text for 5x+ performance gain
- [x] **PERF-02**: Text measured once in init() and cached (not measured every frame)
- [x] **PERF-03**: Semi-transparent curtains use rgba() colors instead of globalAlpha for GPU efficiency
- [x] **PERF-04**: ShadeBar extends AnimatedBar with inheritance pattern from v1.0
- [x] **TEST-01**: Unit tests verify hold duration calculation for short/medium/long text edge cases
- [x] **TEST-02**: Unit tests verify text-curtain synchronization (timing assertions)
- [x] **TEST-03**: OBS browser source testing validates fillStyle rendering and font loading

## Out of Scope

Explicitly excluded features with reasoning:

| Feature | Reason |
|---------|--------|
| Backdrop blur effects | Canvas doesn't support backdrop-filter, GPU-intensive |
| Configurable scroll speed | Defeats dynamic timing algorithm, adds complexity |
| Multiple scrolling text lines | Readability degrades, timing coordination nightmare |
| Real-time text updates during hold | Breaks one-shot OBS pattern |
| Per-character color animation | GPU overhead, visual noise |
| Event-driven automatic triggers | Requires OBS WebSocket setup, validate UX with manual trigger first |
